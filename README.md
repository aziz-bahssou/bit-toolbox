# Bit Toolbox

A small C project where I practice low-level programming and explore how bits and memory work.

## What's inside?

- Bit operations: set, clear, toggle, get and write bits.
- Bit analysis: count set bits, check powers of two, and find bit positions.
- Bit manipulation: reverse, rotate and swap bits or bytes.
- Bit masks: create, extract and insert bits.
- Memory tools: print binary values and dump memory in hexadecimal.

## Compilation

```bash
gcc -Wall -Wextra -Werror main.c bits.c -o bit_toolbox
```

Run it:

```bash
./bit_toolbox
```

## Goal

I'm building this project to improve my C skills, understand bitwise operations, and get more comfortable with low-level programming.
